# Support

Thanks for using Scale Sentry. Here is where to go depending on what you need.

## Documentation

- Project docs: https://ethan-kane-ops.github.io/scale-sentry/
- README: [README.md](./README.md)
- CRD field reference: the **API Reference** page in the docs site.

## Questions and usage help

Open a [GitHub issue](https://github.com/ethan-kane-ops/scale-sentry/issues/new/choose)
using the question or feature-request template. Please search existing issues first.

## Bugs

File a bug with the bug-report template at
https://github.com/ethan-kane-ops/scale-sentry/issues/new/choose. Include your
Kubernetes version, the chart version, and the `ScaleValidation` spec plus status
that reproduces the problem.

## Security vulnerabilities

Do **not** open a public issue for a security problem. Report it privately via a
[GitHub Security Advisory](https://github.com/ethan-kane-ops/scale-sentry/security/advisories/new).
See [SECURITY.md](./SECURITY.md) for the disclosure policy.
