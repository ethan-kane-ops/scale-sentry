## Install

```bash

  oci://ghcr.io/ethan-kane-ops/charts/scale-sentry \
  --version 0.2.0 \
  --namespace scale-sentry --create-namespace
```

The image and chart are cosign-signed and carry SLSA provenance. See the
[project documentation](https://ethan-kane-ops.github.io/scale-sentry/security/)
for verification steps.
