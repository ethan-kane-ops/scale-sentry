Maintainership is earned through sustained, high-quality contributions: reviews, issue triage, and features that land cleanly. If that describes you after a few months of activity, open an issue and ask.

Security reports go through [GitHub Security Advisories](https://github.com/ethan-kane-ops/scale-sentry/security/advisories/new), never public issues. See [SECURITY.md](./SECURITY.md).
