## [0.0.0-rc1] - 2026-05-25

### Features

- *(release)* GHCR multi-arch images + OCI helm chart on tag push (#11)
- *(loadgen)* Configurable TLS (InsecureSkipVerify + custom CA bundle)
- *(e2e)* Full verdict E2E with metrics-server + hpa-example (#9)
-   feat(observer): wire cluster observation via Job sidecar (#6)

ENG-36 — real cluster data now feeds the analyzers. A new observer
  runs as a native sidecar in the loadgen Job, holds the only K8s
  client besides the controller, drives every analyzer package, and
  reports diagnostics the controller folds into ScaleValidation status.

  Architecture: the per-run observation lives in a Pod whose lifetime
  equals the run, not in a controller goroutine. The controller stays
  a thin, stateless, edge-triggered orchestrator — leader failover is
  lossless and controller cost does not scale with concurrent runs.

  - internal/loadgen: Result gains []ErrorSample, one timestamped entry
    per failed request (capped at 10000). cmd/loadgen --result-file
    writes the Result JSON to the Job's shared volume.

  - internal/observer + cmd/observer: the observation sidecar. Polls
    the target HPA into hpa.Watcher, watches EndpointSlices (an
    endpointTracker diffs slices into per-IP Ready/Removed events for
    leakage + drain), execs `cat cpu.stat` for the cgroup throttle
    comparison, collects the cold-start pod's conditions for probelag,
    reads the loadgen result file, runs every analyzer, and prints the
    Report as a single SCALE_SENTRY_REPORT marker line. Every data
    source degrades gracefully to an Unknown verdict.

  - internal/controller: the loadgen Job now carries the observer as a
    native sidecar (restartPolicy:Always init container) sharing an
    emptyDir, running as a ServiceAccount, with a 45s grace period.
    resolveTargetURL became a method — AutoDiscoverProbe fetches the
    target Deployment and resolves its readiness probe. On Job
    completion the reconciler waits for the observer to terminate,
    reads its pod log, parses the Report, writes status.diagnostics
    and the measured metrics, and sets the Failed phase when the SLA
    or traffic-integrity verdict failed.

  - config/rbac: hand-written observer_role.yaml (namespaced SA + Role
    + RoleBinding — deployments get, pods get/list, pods/exec create,
    endpointslices list/watch, hpa get/list). manager role.yaml
    regenerated to add pods and pods/log.
